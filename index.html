Is this message a scam? See which words gave it away.

An NLP model trained on 5,169 real text messages. Paste any SMS and it scores it as you type, highlighting the words that pushed it towards scam or safe. Nothing leaves your browser.

    Ready for a bot

    The repo includes a FastAPI service around the same model. A WhatsApp, Telegram or email bot can send it any message and get back a score and the reasons.

    curl -X POST localhost:8000/check \
  -d '{"text": "You won Rs 50,000. Call 9876543210 to claim"}'

{"scam_probability": 0.9998, "is_scam": true,
 "top_signals": [{"term": "_phone_", "weight": 2.718},
                 {"term": "_money_", "weight": 1.887},
                 {"term": "call _phone_", "weight": 1.585}]}

    The data

    The SMS Spam Collection (Almeida & Hidalgo, UCI repository): 5,169 unique real messages, 653 of them spam. 80% for training, 20% held back and used once for the results above.

    The model

    Links, phone numbers, amounts and codes are replaced with tokens like _url_ and _phone_, so the model learns the pattern rather than one number. Then TF-IDF over words and word pairs, and logistic regression with balanced class weights.

    Why this model

    Naive Bayes, logistic regression and a linear SVM all reached an F1 of about 0.96 in cross-validation. Logistic regression was kept because every word has a readable weight, which is what makes the highlighting possible.
